# Northstar Technologies — Company Overview

## Organization

Northstar Technologies is a fictional technology company used for this IT Help Desk and Troubleshooting Simulation.

The organization has approximately 50 employees distributed across several business and technical departments.

## Departments

- IT
- Human Resources
- Finance
- Sales
- Operations
- Management

## IT Support Environment

The IT Help Desk is responsible for supporting users with:

- Network connectivity
- DNS and name resolution
- VPN connectivity
- User account issues
- File and folder permissions
- Software and application issues
- Basic workstation troubleshooting

## Simulated Infrastructure

The project models a small business environment containing:

- Windows-based user workstations
- Local user accounts for controlled testing
- Network connectivity through a gateway
- DNS resolution
- VPN access requirements
- File and folder access permissions
- Business applications

## Support Approach

Help Desk technicians follow a structured troubleshooting process:

1. Identify and document the reported issue.
2. Gather relevant symptoms and evidence.
3. Reproduce the issue when possible.
4. Perform diagnostic tests.
5. Identify the likely root cause.
6. Apply the appropriate resolution.
7. Verify that the issue is resolved.
8. Document the findings and preventive actions.

## Project Scope

This environment is fictional and created solely for educational and portfolio purposes.

No production company infrastructure was intentionally modified during this project.
