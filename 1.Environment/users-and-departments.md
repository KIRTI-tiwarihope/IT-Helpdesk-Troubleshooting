## User Support Scenarios

The Help Desk may receive requests such as:

- "I cannot connect to the network."
- "Websites are not loading."
- "My VPN is not connecting."
- "My account is locked."
- "I cannot access a Finance file."
- "An application is not opening."

These scenarios are represented by the six incident tickets in this project.

## User Account Model

The simulated environment uses local Windows accounts for controlled laboratory testing.

Example test accounts include:

- `IT-TestUser` — used for account troubleshooting
- `Finance-TestUser` — used for permissions testing

These accounts were created specifically for the lab and are not production accounts.

## Access Principles

The simulated Help Desk follows basic security principles:

- Least privilege
- Need-to-know access
- Separation of administrative and standard-user activities
- Controlled testing
- No unnecessary modification of system settings

## Scope

This user and department structure is fictional and exists solely for educational and portfolio purposes.
