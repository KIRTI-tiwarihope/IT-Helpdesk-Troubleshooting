# Software Troubleshooting Guide

## Purpose

This document records the software troubleshooting process used during the Help Desk simulation.

## Troubleshooting Steps

### 1. Verify the Application

Check that the application is installed on the computer.

### 2. Try Launching the Application Again

Attempt to open the application from the Start menu or desktop shortcut.

### 3. Check Running Processes

Open Task Manager and check whether the application is already running.

### 4. Restart the Application

Close any existing application process and attempt to launch it again.

### 5. Restart the Computer

Restart Windows and test the application again.

### 6. Check System Resources

Use Task Manager to check CPU, memory, and disk usage.

### 7. Check Event Viewer

Open:

Event Viewer → Windows Logs → Application

Look for errors occurring at the time the application failed.

## Final Diagnosis

The issue was treated as a simulated application startup problem.

No critical Windows system failure was identified.

## Resolution

The application was restarted and the computer was rebooted as standard troubleshooting steps.

## Verification

The application was tested again after troubleshooting.

## Escalation

If the problem continues, the Help Desk should:

1. Document the error message.
2. Record when the problem occurs.
3. Check whether other users are affected.
4. Verify application version and updates.
5. Escalate to the application support team when necessary.

## Help Desk Best Practice

Always document the symptoms, troubleshooting steps, findings, resolution, and verification results before closing a software-related ticket.
